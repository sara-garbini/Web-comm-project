# Digital Comm Career Hub

Welcome to the **Digital Comm Career Hub**, an interactive web platform designed to bridge the gap between academic paths in Digital Communication and the global professional job market. 

The application is built entirely in **Python** and leverages the **Streamlit** framework to deliver a dynamic, responsive user experience tailored for both desktop and mobile devices.

---

## Key Features

* **Job Opportunities & Filtering:** Advanced consultation and filtering of the most relevant job vacancies and internships within the digital communication sector.
* **CV Guidance:** Strategic and editorial tips to structure an effective curriculum vitae, fully optimized for ATS (Applicant Tracking Systems) and aligned with European recruitment standards.
* **🇪🇺 Erasmus+ Traineeship Guide:** A step-by-step roadmap to support students in accessing international mobility programs and European grants.
* **Responsive UI/UX:** A highly polished graphical interface built using custom CSS styles, featuring smooth animations and native Dark Mode compliance.

---

## Tech Stack & Architecture

The project uses modern technologies for web development and data management:

* **Frontend & Backend:** [Streamlit](https://streamlit.io/) (Python Framework)
* **Data Manipulation:** [Pandas](https://pandas.pydata.org/) for loading, cleaning, and filtering the job opportunity datasets.
* **Styling & Animations:** Native HTML5 and custom CSS3 (injected via `st.markdown`) to manage flexible layouts (Flexbox), mobile media queries, and keyframe animations.
* **Version Control & Hosting:** Git, GitHub, and Streamlit Cloud for continuous deployment.
